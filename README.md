# TCCC / CLS – interaktiv träningssida

## Struktur
- `index.html` – själva hemsidan
- `filmer/` – MP4-filmer
- `bilder/` – framtida separata utbildningsbilder

Blodsvepsfilmen ligger i `filmer/blodsvep.mp4`.

## GitHub Pages
Ladda upp hela innehållet med samma mappstruktur. GitHub Pages ska använda repositoryts root som publiceringskälla.

När fler filmer läggs till placeras de i `filmer/`, till exempel:
- `filmer/tourniquet.mp4`
- `filmer/tamponering.mp4`
- `filmer/airway.mp4`

HTML-filen behöver då bara referera till respektive fil och förblir liten.
